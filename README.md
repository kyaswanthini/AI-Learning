# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer built using Python, Streamlit, and Google Gemini AI.

This application compares a resume against a job description and provides:
- Match score
- Matched skills
- Missing skills
- Improvement suggestions
- Hiring recommendation

---

## 🚀 Features

✅ AI-powered resume analysis  
✅ Job description matching  
✅ Skill gap detection  
✅ Gemini API integration  
✅ Streamlit web interface  
✅ Simple and clean UI

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/kyaswanthini/ai-resume-analyzer.git
```

### 2. Navigate to Project

```bash
cd ai-resume-analyzer
```

### 3. Install Dependencies

```bash
pip install streamlit google-genai
```

---

## 🔐 Setup Environment Variable

### Mac/Linux

```bash
export GEMINI_API_KEY="your_api_key_here"
```

### Windows

```bash
set GEMINI_API_KEY=your_api_key_here
```

---

## ▶️ Run Application

```bash
streamlit run streamlit_app.py
```
